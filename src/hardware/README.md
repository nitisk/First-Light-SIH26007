# Hardware code

- `arduino/rover_firmware/`: Uno firmware.
- `raspberry_pi/`: host controller, USB communication and Wi-Fi warnings.
- `config.json`: calibration and speed settings.
- `requirements.txt`: pyserial dependency.

For setup, wiring and run commands, see [hardware notes](../../docs/hardware.md). The `--mock` mode uses simulated readings and needs no connected board.
